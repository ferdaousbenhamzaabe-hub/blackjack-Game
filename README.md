# 🃏 Blackjack Game

A customizable, interactive web-based Blackjack game built with plain HTML, CSS, and JavaScript.

## 🎮 Features

- **Dynamic Betting:** Enter custom bet amounts before starting a new round.
- **Custom Target Score:** Set your own target score dynamically (defaults to 21) using the target confirmation button.
- **Chip Management:** Real-time tracking of player chips and active bets.
- **Core Game Logic:** Random card generation, hit/stand mechanics, and automatic win/loss detection.

## 🛠️ Built With

- **HTML5** — Document structure
- **CSS3** — Custom styling and casino table aesthetics
- **JavaScript (ES6)** — Game state management and DOM manipulation
